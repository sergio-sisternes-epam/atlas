# Thoughtful current-theory memory building

Use when findings should become Atlas **lessons**, live **decisions**, or **recipes**.

## Always required (agent thinking)

1. Atlas activation card with `path: remember` and `path_module: references/paths/remember.md`.
2. A designed inventory the agent actually thought through: proposed path, type, one-line claim, source URIs. Dumping unexamined text into a lesson is forbidden.

After that inventory exists, **write and compile**. Do not wait for a human unless they asked.

## Optional human hold

If the human asks for review, calls the persist important, or says hold / approve first:

- show the inventory
- do not compile those current-theory pages until they approve or name a subset

Silence is not a hold. “Interesting” is not a hold. An explicit review request is a hold.

## Not this recipe

Discussion fabric (`experience`, discuss hubs, protostars, constellation views) stays on discuss / Autogenesis path discuss.
